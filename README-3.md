# Отчёт по авансам по договорам

Программа строит отчёт: по каждой работе — цена, выплачено, осталось; по каждому договору — итоги.

## Запуск

```bash
cd advance_report
python3 report.py
```

Дата отчёта зашита как `2026-11-10`. Чтобы поменять — отредактируй `REPORT_DATE` в `report.py`.

## Файлы

- `report.py` — скрипт
- `data/` — исходные CSV
- `DECISIONS.md` — принятые решения
- `записка_бухгалтеру.txt` — пояснение для бухгалтера
